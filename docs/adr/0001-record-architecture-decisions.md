# 0001. Record architecture decisions

Date: 2026-09-02
Status: Accepted

## Context

The project starts small with one contributor and an AI assistant doing
much of the typing. Reasons for choices are easy to lose in that setup.

## Decision

Record significant technical decisions as short ADRs in `docs/adr/`.

## Consequences

Slightly more writing up front. Far less "why is it like this?" later,
and a place for automated runs to read constraints from.
